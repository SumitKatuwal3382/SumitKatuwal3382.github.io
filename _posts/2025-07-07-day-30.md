what_i_learned: |
 Today, I learned how to transform structured football match data into natural, human-like commentary using AI-driven summarization. I explored how to build a prompt that simulates a dialogue between two sports commentators, generating a dynamic summary that highlights match statistics, key events, and narrative flow. I discovered the importance of crafting prompts with variety and context to ensure the summaries feel unique and engaging for each game. By using OpenAI's chat.completions, I learned to turn raw numbers and events into conversational insights that mirror real-world sports broadcasts. While my code currently prints text commentary, it lays the groundwork for generating audio using text-to-speech (TTS) tools like ElevenLabs, Google TTS, or Amazon Polly. This opens up the possibility of creating fully automated, realistic post-match audio recaps. Overall, I bridged the gap between data analytics and storytelling, taking a major step toward building intelligent, voice-ready sports media tools.


blockers: |
  Today, I faced a few blockers while working on the project. First, handling incomplete or missing data from the API occasionally caused errors when generating match summaries. I also found it challenging to ensure the AI-generated commentary felt unique for each match, despite using similar prompt structures.
