 Today, I learned how to work with audio in Python using different tools. I discovered that the sounddevice library allows recording audio from a microphone, but this doesn't work in Google Colab because it cannot access local hardware. I also learned that converting text to speech is a different process from recording voice and requires a Text-to-Speech (TTS) library like gTTS. Using gTTS in Colab, I was able to convert a text summary into an audio file and play it back. Overall, I gained a clearer understanding of which tools to use depending on whether I'm working with voice input or generating speech from text.
